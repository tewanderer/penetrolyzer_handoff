# penetrolyzer_handoff
Uploading my files for the MSTAR penetrolyzer along with some explanations for whoever picks up the project next


If you are reading this you are either ElShafie, or someone who will be working in his lab at COD tackling the penetrolyzer.

It's an interesting project where you will learn CAD (solidworks, fusion360), 3D printing (bambu studio), building scientific apparatus, and how to source scientific equipment online (McMasterCarr, Kurt J Lesker, digikey, etc.).

Simply put, the penetrolyzer is a mobile electrolysis unit. The main research focus at MSTAR is electrolysis to extract hydrogen and oxygen from martian regolith. You are going to make a mini electrolysis chamber that goes on a rover for easy deployment. It has to penetrate into the regolith and analyze it, hence, penetrolyzer. You can ask ElShafie for the details. I'm writing this to show where I left off and prepare you to jump into prototyping this device.
